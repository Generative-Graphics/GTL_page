# Gen Through the Lens — Project Page

Static project page for **Gen Through the Lens: Camera-Controllable Video Generation via Cross-Coordinate Conditioning Fusion**.

- Paper: https://arxiv.org/abs/2610.15900
- Deployment: GitHub Pages
- Stack: HTML, CSS, and vanilla JavaScript

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Add videos

The main and case-study video blocks in `index.html` are marked with HTML comments. Replace each placeholder with a `<video>` element (recommended: MP4/H.264 plus WebM fallback) or an iframe embed.
